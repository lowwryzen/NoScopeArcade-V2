# <p align="center"> No Scope Arcade V2 
</p>

---

A proposta desse projeto, é ser um jogo dinâmico, onde o jogador principal `(player)` carrega consigo uma sniper sem mira, onde o objetivo por enquanto, será eliminar seus adversários.
O jogo terá uma movimentação dinâmica, algo como `DOOM Eternal`, onde será possível fazer `parkour` no ambiente.
